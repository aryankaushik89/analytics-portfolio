# Synthetic commercial data

The three CSV files and `metrics_demo.sqlite` are generated by `src/generate_data.py` with seed 89.

They contain fictional customer identifiers, segments, regions, monthly subscription values and invoices. They do not describe real people, companies, Stripe accounts or employers.

The authored data is dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Project code is covered by the MIT licence.
