# Synthetic data

`synthetic_transactions.csv.gz` contains 60,000 authored demonstration records created by `src/generate_data.py` with seed 89.

The records do not describe real people, cards, merchants, employers or payment activity. Transaction IDs are sequential project identifiers and cannot be linked to an external identity.

The generated dataset is dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The project code that creates and analyzes it is covered by the repository's MIT licence.
